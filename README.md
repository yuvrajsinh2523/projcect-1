# Yuvran BnB

A full-stack Airbnb-style listing web application built using Node.js, Express.js, MongoDB, EJS, and Bootstrap.

## 🚀 Features

- Add new property listings
- View all listings
- View detailed property pages
- Edit existing listings
- Delete listings
- Responsive Bootstrap UI
- MongoDB database integration
- Dynamic EJS templating
- RESTful routing
- MVC-style project structure

---

## 🛠️ Tech Stack

### Frontend
- HTML5
- CSS3
- Bootstrap 5
- EJS

### Backend
- Node.js
- Express.js

### Database
- MongoDB
- Mongoose

## ⚙️ Installation

### Clone Repository

```bash
git clone https://github.com/yuvrajsinh2523/projcect-1.git
```

### Move into project folder

```bash
cd projcect-1
```

### Install dependencies

```bash
npm install
```

### Run server

```bash
node app.js
```

OR

```bash
nodemon app.js
```
